# Phrase Mystère – formation CRB

Jeu de la phrase mystère : les joueurs proposent des lettres, et chaque lettre
trouvée apparaît partout où elle se trouve dans la phrase.

Jouer : https://ghibau.github.io/CRB/
(sur iPhone, ouvrir ce lien dans Safari)

## Règles
- Une lettre par case rose, 27 cases au maximum.
- Une lettre déjà proposée est refusée.
- Le bouton « Indice » propose une lettre restante, autant de fois que nécessaire.
- « Révéler la phrase » affiche la solution sans feu d'artifice.

## Modifier la phrase
Les lignes sont dans le tableau `LINES` du fichier `index.html`.
Les lettres entre crochets, comme `[L]A`, sont visibles dès le départ.
